# TulongTools

A mobile-friendly barangay equipment borrowing catalog and management interface.

## Run locally

Serve this folder with Apache/XAMPP or another static web server, then open `index.html`. No build step is required.

## Data and security

This demo stores data in the browser's local and session storage. It does not provide server-side authentication or cross-device synchronization, so do not use it to store sensitive production records.
